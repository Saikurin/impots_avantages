# Frontend

Socle frontend prevu pour Angular.

## Structure

- `src/app/core/` : services globaux
- `src/app/shared/` : composants et utilitaires partages
- `src/app/bundles/` : fonctionnalites par bundle

## Premier bundle

`src/app/bundles/frais-kilometriques/` contiendra :
- le wizard de saisie
- les ecrans de recapitulatif
- l'ecran de resultat
