# Backend

Socle backend prevu pour Django.

## Structure

- `config/` : configuration Django
- `apps/common/` : code partage
- `apps/bundles/` : bundles metier
- `tests/` : tests transverses

## Premier bundle

`apps/bundles/frais_kilometriques/` contiendra :
- modeles
- services de calcul
- validations metier
- API
